Terminal & desktop text search

Find the exact line,
every time.

CodeLens is a precision line & symbol search tool for any text file — a self-contained terminal app and a glassy desktop app, sharing one search engine. Built to avoid the spacing bugs, missing line numbers, and stale caching of an editor's Find box.

by Robin Gupta

See it in action

Two flows, animated.

Illustrative walkthroughs of the two things you'll do most — searching, and trusting that what you see is never stale.

Two front-ends, one engine

Pick your surface. The search is identical.

The desktop app imports its matching, comment-fallback, and encoding logic straight from the terminal script — there is exactly one implementation of “does this line match,” not two copies that could quietly drift apart.

CodeLensCLI.py — terminal

python CodeLensCLI.py
  • Standard library only — colorama is used if present, otherwise raw ANSI.
  • Tab-completion, paste-and-go file loading, recursive filename search.
  • remove unloads files without touching disk; reset always warns before clearing state or everything.
  • Borders and menus re-measure the terminal's real width on every draw — no stale overflow in a resized window.

CodeLens.py — desktop

python CodeLens.py
  • Glassmorphism UI with a theme & glass-effect toggle, both animated.
  • Custom accent-color picker, custom checkboxes, custom animated dialogs — no stock system chrome.
  • Drag & drop, three file-list views, a resizable preview window, zoom in/out.
  • Every shortcut is editable live and saved to shortcuts.json.
Search modes

Three ways to ask the same question.

Every loaded file is searched at once, grouped per file with match counts — and each search silently reloads any file that changed on disk since it was opened.

One line

Exact literal match

Case-sensitive or not. Include a comment in what you type if you need that exact commented line, and nothing else.

Multi line

Whitespace-insensitive snippet

Paste a block spanning any number of lines. Falls back automatically to a comment-stripped comparison if the plain match finds nothing.

Line range

Show exactly these lines

A specific start-end (or single line) from one loaded file, chunked automatically for very large ranges.

Desktop edition

Everything the glass app can do.

Theme + glass toggle

Dark/light and a frosted-glass look, both on by default, both crossfade when switched.

Custom accent picker

A hand-drawn glassy swatch grid plus hex entry — not the stock OS color dialog.

Custom dialogs & checkbox

Every confirm/info box fades and scales in, glass-matched — no native message boxes anywhere.

Three list views

Detail list, icon grid, or grouped by folder — files sharing a directory collapse into one section.

Drag & drop

Drop files anywhere on the window from Explorer to add them to the working set.

Preview + zoom

Double-click a file for a resizable Formatted/Raw viewer with independent wrap and zoom.

Hamburger explorer

Hide or show the file-list panel; it remembers its width when it comes back.

Resizable panes

Search and results split like a file explorer — drag the divider to resize either one.

Full details table

A separate sortable window: lines, size, encoding, modified time, and full path per file.

Icon system

One shape, two palettes, one rescue set.

Every icon is a real vector under Assets/ — Qt loads SVG natively, no rasterizer needed. DarkModeIcons/ and LightModeIcons/ share filenames but not color; HoverIcons/ is a single white set used the instant a button's background turns solid, since a themed icon tinted for its resting state disappears against its own hover color.

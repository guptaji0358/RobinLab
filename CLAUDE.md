# RobinLabs

This repo contains multiple independent static-site/app projects:

- `root/` — main site (plain HTML/CSS/JS)
- `CodeLens/` — static site
- `Contact Book/` — static site / app landing page
- `Pywix/` — static site / app landing page

Each project is self-contained (own `assets/`, `css/`, `js/`). No shared build system.

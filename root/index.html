About

I’m Robin Gupta. RobinLab is the name I build under — a one-person software studio for the tools I design, write, and ship in my own time. The apps run on Windows, and most of them start as an annoyance I got tired of living with.

The current lineup is four desktop apps: PyWix, a PySide6 GUI that wraps PyInstaller so a Python script becomes a real Windows app; CodeLens, a precision line and symbol search tool for any text file; Contact Book, a local-only address book with drag-and-drop VCF import and Phone Link calling; and Motiva, a native C++/Qt 6 app that plays videos and GIFs as your desktop wallpaper.

Collection and Presentations are the other half of the site: wallpaper packs I’ve collected and organised, and the slide decks I build for college students. The decks are free to download — if you need one on a different topic, ask me.

Open to questions, bug reports, or a build you’d like to see: hema82471@outlook.com.

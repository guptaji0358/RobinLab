Claude Skills

    

      Reusable instructions I give Claude so it works the way I do — renaming
      files, writing notes, translating documents, handing off projects. They are
      read from the vault, so new skills show up here on their own.

Method: how I get results from a skill

    
    
      
  1. 
        1
        
    Name the goal
    
        
    One sentence on what “done” looks like — a renamed folder, a finished
        study guide, a translated deck.
    
      
    2. 
      
  2. 
        2
        
    Pick the skill
    
        
    Match the goal to a card above and use its trigger words
        (“create a handoff”, “translate this”). Claude loads it itself.
    
      
    3. 
      
  3. 
        3
        
    Answer its questions
    
        
    Good skills ask before they act. Short, specific answers mean less redoing later.
    
      
    4. 
      
  4. 
        4
        
    Check, then approve
    
        
    Read the proposal before anything changes. Renames, edits and translations
        only happen after a clear yes.
    
      
    5. 
      
  5. 
        5
        
    Keep the result
    
        
    Save the output. When a run goes wrong, tweak the skill file so the next run starts better.
    
      
    6. 
    


    
Have these ready before you start

    
    
      
  • What is the goal?The one thing you want at the end.
    • 
      
  • What do you already have?The files, code, links or notes Claude should start from.
    • 
      
  • How deep, and for whom?Beginner or advanced, quick pass or full reference.
    • 
      
  • What format do you want back?Markdown, .docx, .pptx, a PDF, or commands to run yourself.
    • 
      
  • What must not change?Names, structure or wording that has to stay as it is.
